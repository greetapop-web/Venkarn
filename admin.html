เวรกรรณ Admin

สำหรับผู้จัดเวร · ต้องใส่รหัสผู้ดูแลครั้งแรก 🔒

📲 เพิ่มไอคอน Admin ไว้หน้าจอโฮม

  1. เปิดหน้านี้ใน Safari (ถ้าเปิดจากไลน์ ให้กด ⋯ แล้วเลือก "เปิดใน Safari")
  2. แตะปุ่มแชร์ แชร์ ด้านล่างจอ
  3. เลื่อนหา ➕ เพิ่มไปยังหน้าจอโฮม
  4. กด เพิ่ม แล้วจะมีไอคอนเวรกรรณ Admin บนหน้าจอ
  1. เปิดหน้านี้ใน Chrome (ถ้าเปิดจากไลน์ ให้กด ⋮ แล้วเลือก "เปิดในเบราว์เซอร์อื่น")
  2. แตะ ⋮ มุมขวาบน
  3. เลือก เพิ่มลงในหน้าจอหลัก หรือ ติดตั้งแอป
  4. กด เพิ่ม แล้วจะมีไอคอนเวรกรรณ Admin บนหน้าจอ
